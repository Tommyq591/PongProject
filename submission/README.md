## `writeup_source/`: source of the draft PDF

| file | what it is |
|---|---|
| `writeup.md` | The text of the write-up: sections follow the brief's Option 2 marking scheme. Placeholders are marked `[PLACEHOLDER ...]` and `[RESULTS PENDING ...]`. |
| `build_pdf.py` | Draws the two diagrams (`figures/nature_cnn.png`, `figures/update_flow.png`) and builds the PDF into `actual_submission/`. Needs `reportlab` in the `.venv`. |
| `requirements.txt` | The extra package for the PDF build: `reportlab` (pinned). It is not in `Assignment2/requirements.txt`, because the notebook doesn't need it. |
| `figures/` | Images used by the write-up. The two diagrams are generated by `build_pdf.py`; the others are copies of `results/` and `experiments/04_diagnosis/observations.png`. Copy the updated images here when the results change. |

Rebuild after editing `writeup.md` (from the repo root):

```powershell
.venv\Scripts\python -m pip install -r submission\writeup_source\requirements.txt   # once (reportlab)
.venv\Scripts\python submission\writeup_source\build_pdf.py
```

Before the final version, remove the "DRAFT" banner and footer (the `banner:` line in `writeup.md` and `on_page()` in `build_pdf.py`), fill in every placeholder and add the main-experiment results. Every number in the write-up must come from a recorded file.
